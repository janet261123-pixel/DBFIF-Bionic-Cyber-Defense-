## 第一章：核心願景與仿生哲學 (Vision & Bionic Philosophy)

* **痛點與初衷**：傳統城市 lighting 存在兩大痛點——山區拉設線纜工程昂貴且易遭竊；固定色溫燈具在極端天候（如濃霧）下無法兼顧辨識度與安全。
* **生態共生哲學**：回歸大自然節律，減少夜間光害干擾，保護夜行性昆蟲與植物的生理時鐘。以「需亮才亮、因地制宜」為核心，把安靜與黑夜還給大地。

## 第二章：硬體與工程降本架構 (Hardware & Off-Grid Engineering)

* **極致去纜線化 (Off-Grid)**：
  * 每支路燈均為獨立的「太陽能蓄電＋微型能源站」，零台電纜線、零溝渠開挖，施工即插即用，材料與工程成本驟降 70% 以上。
  * **低電量降頻保護 (Power-saving Fallback)**：若遇連續極端陰雨天，電量低於 20% 時自動進入省電模式，縮短感應距離並降低微光亮度，優先確保「動態觸發照明」，達成永不停機。
* **AI 動態雙色溫切換**：
  * 燈體內建高演色性白光與高穿透力暖黃光雙模組。
  * 平時提供清晰對比的白光；當微型感測器偵測到空氣濕度與霧氣散射升高時，AI 即刻自動切換為暖黃光，強效穿透濃霧。

## 第三章：通訊韌性與智慧圖資對接 (Mesh Communication & Digital Twin)

* **自癒型無線蜂群網路 (Self-Healing Wireless Mesh)**：
  * 節點間免鋪光纖，透過低功耗無線通訊（Zigbee/LoRa/Mesh）彼此串聯。當前導路燈偵測到動態，立即預先點亮前方的「陪伴光廊」。
  * 若單一節點受損，Mesh 網路會自動繞過故障點、連線至下一節點，確保訊號鏈路永不斷線。
* **Google Maps 數位雙生 (Digital Twin API Integration)**：
  * 實時回傳路面障礙（如積水、落石）與微氣候數據（如 PM2.5、溫濕度）至 Google Maps 圖資，為駕駛人與市府指揮中心提供實時動態地圖。
* **可選配模組化擴充 (Modular Extensions)**：
  * 針對治安重點區域，可選配「微型 AI 邊緣算力模組」，進行改裝車噪音或違規環境傾倒的自動拍照鎖定。
